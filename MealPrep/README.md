# Sunday Kitchen

A standalone, UI-only meal-prep planner prototype. It does not use Vue, call an AI service, or send your preferences anywhere. The plan and shopping list are sample content for exploring the interface.

## Run it

Open `index.html` in a browser. No build step or package installation is required.

## Prototype interactions

- Adjust serving count and grocery budget.
- Choose a meal-prep style and dietary preferences.
- Switch between the sample meal plan and shopping list.
- Check off groceries, copy the list, or print the current view.
- Build the week to preview the local, sample-only response state.
